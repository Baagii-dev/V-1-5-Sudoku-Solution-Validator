Эцэг урсгал нэгтгэнэ

Эцэг урсгал хүснэгтийг дамжуулж, бүх урсгалыг хүлээн үр дүнг нэгтгэнэ.

Хэрхэн ажилладаг вэ

  1. Оролтын текстийг 9x9 хүснэгт болгон уншиж, алдааг мөр, баганаар нь тэмдэглэнэ.
  2. Бүлэг бүрийн 9 нүдэнд давхардал эсвэл 1–9-өөс гадуур утга байгааг шалгана.
  3. Урсгал бүр хүснэгтийг зөвхөн уншиж, үр дүнгээ өөрийн нүдэнд бичдэг тул lock хэрэггүй.
  4. Эцэг урсгал бүгдийг хүлээж, нэгтгэсэн дүгнэлт (Зөв / Буруу шийд) гаргана.

Гурван хувилбар

Python хувилбар

Python-ы threading буюу үйлдлийн системийн жинхэнэ урсгал ашиглана. Сервер (python3 src/app.py) дээр шалгалт хийгдэнэ. Даалгаварт тавигдсан үндсэн хэрэгжүүлэлт.

C хувилбар

Сурах бичгийн Programming Project-ийн адил POSIX Pthreads (pthread_create/pthread_join) ашиглана. Linux, macOS дээр cd src/c && make гэж build хийж командын мөрөөс ажиллуулна.

Онлайн хувилбар

React болон хөтчийн Web Worker урсгал ашиглана. Суулгах, татах шаардлагагүй, линкээр шууд нээгдэнэ (GitHub Pages).
